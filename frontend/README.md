# Aquafound Frontend

Vite + React site for Aquafound marketing, lead capture, and scheduling.

## Quick start
1) `cd frontend`
2) `npm install`
3) `npm run dev`
4) Open the URL Vite prints (usually `http://localhost:5173`)

## API base URL
By default the UI calls `http://localhost:5000`. To point elsewhere, set:

```
VITE_API_BASE=http://localhost:5000
```
